
# FormFieldKit

A lightweight, type-safe form validation system for SwiftUI.

## Features

- ✅ Generic `FormField<T>` with optional title, placeholder, value, and error state
- ✅ Composable validators via `Validator<T>`
- ✅ SwiftUI-ready with helper bindings (`.text`, `.errorText`, `.hasError`)
- ✅ Built-in string validators: `.nonEmpty`, `.isNumber`, `.minLength`, etc.
